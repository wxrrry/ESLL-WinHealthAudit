The audit now keeps score: a health number, what changed since the last run,
and a way to make repeating noise disappear.

## Highlights

- **Health score 0–100** in the header — every critical finding costs 8
  points, every warning 2. The same number lands in the `--json` output
  (`health`) and at the top of the markdown report, so you can watch it move
  between runs.
- **Since the last run** — the previous result is remembered locally
  (`last-result.json`); the findings list gets a delta line (`N new ·
  M resolved`) and a `NEW` badge on rows that were not there last time.
  Counts and percentages are normalized away, so a volume going from 6.2% to
  5.9% free is the same finding, not a new one.
- **Hide a finding** you already know about — the expanded row has a *hide*
  button; hidden rows leave the list and the count, and the *hidden* chip
  next to the filter shows how many are parked (click it to bring them back,
  click *hide* again to un-hide). The list lives in `settings.json`.
- **Hotkeys**: `R` re-runs the audit, `/` focuses the filter box, `1` `2` `3`
  switch the Findings / Checks / Log tabs, `Esc` clears the filter or folds
  open rows.
- The report header gained `- Health: N / 100`.

Аудит теперь ведёт счёт: оценка здоровья, дельта с прошлого запуска и способ
убрать надоевший шум.

- **Оценка здоровья 0–100** в шапке: каждая критическая находка снимает 8
  очков, каждая «внимание» — 2. То же число попадает в `--json` (`health`) и
  в начало markdown-отчёта.
- **С прошлого запуска** — предыдущий результат запоминается локально; над
  списком появляется строка дельты («новых · исчезло»), а у новых строк —
  бейдж **новая**. Цифры и проценты в сравнении нормализуются: изменение
  свободного места с 6.2% до 5.9% — та же находка, а не новая.
- **Скрытие находок** — кнопка *скрыть* в раскрытой строке; скрытые строки
  пропадают из списка, а фильтр *скрытые* показывает их количество (клик —
  вернуть, *скрыть* снова — разскрыть). Список хранится в `settings.json`.
- **Горячие клавиши**: `R` — повторный запуск, `/` — фокус в фильтр,
  `1` `2` `3` — вкладки Находки / Проверки / Журнал, `Esc` — сброс фильтра
  или сворачивание строк.
- В шапку отчёта добавлена строка `- Health: N / 100`.
