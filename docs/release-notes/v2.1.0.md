# WinHealthAudit \\ ESLL — v2.1.0

## What's New
- **Overview Trends Card**: Added live audit trend sparklines and deltas (`Health`, `C: free %`, `WHEA/min`, `Boot time`) directly to the Overview dashboard.
- **Audit Scoring Criteria & Status Grade**: Added explicit formula (`100 − 8×Critical − 2×Warning`), status grade label (`Excellent` / `Good` / `Fair` / `Critical`), and toggleable Criteria panel in the Audit tab.
- **Upgraded Setup Installer**: Borderless ESLL monochrome installer UI with custom toggles, automatic `WinHealthAudit` folder creation, CLI flags (`/S`, `/D=`, `/DESKTOP`, `/NODESKTOP`, `/STARTMENU`, `/NOSTARTMENU`), and Windows Search / App Paths registration.
- **Updated Documentation & Screenshots**: Refreshed `README.md` (EN/RU) with live screenshots of the new Overview, Audit, Programs, Automation, and Settings views.
