# WinHealthAudit \\ ESLL — v2.0.0

## What's New
- **Unified Windows Control Center** in the original ESLL monochrome aesthetic (`#000` / `#fff`, EN/RU):
  - **Audit**: Original 11 read-only health checks, findings, history sparklines, Markdown & JSON reports.
  - **Overview**: Hardware profile (CPU, GPU, RAM, motherboard, BIOS, displays).
  - **Live Monitor**: Real-time CPU/RAM/GPU/Disk SMART/Network/Battery telemetry, DNS ping & presets, process manager.
  - **Drivers**: Driver inventory, problem devices, Windows Update driver scan, `pnputil` backup export, restore points.
  - **Programs**: Uninstaller with leftover scanner & quarantine/restore, `winget` updater, App Hangar catalog & kits.
  - **Storage**: Drive overview, folder space treemap, largest files, SHA-256 duplicate finder, safe Recycle Bin deletion.
  - **Optimizer**: Temp/cache cleaner, startup apps, services, power plans, Game Mode / HAGS, debloat tweaks, SFC/DISM/network repairs.
  - **Privacy & Security**: Security score, telemetry toggles, open ports, app permissions, persistence audit.
  - **Benchmark**: CPU, GPU (WebGL), memory bandwidth, disk read/write tests & score history.
  - **Device Tester**: Keyboard, dead pixel display test, speakers, microphone, camera, mouse CPS, gamepad.
  - **Automation**: Scheduled Windows maintenance tasks & backups overview.
- **UI Sounds & Smooth Animations**: Subtle `.ogg` audio feedback (toggleable in Settings) and smooth monochrome transitions.
- **Stability & Elevation Fixes**: Eliminated redundant 700ms DOM re-renders; fixed top-right admin elevation button feedback.
- **Installer (`WinHealthAudit-Setup.exe`)**: Installs both `WinHealthAudit.exe` and `WinHealthAudit.Core.exe` together into a chosen directory with optional Desktop & Start Menu shortcuts.
