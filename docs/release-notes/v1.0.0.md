First public release: a read-only Windows health report in **one executable** —
nine checks, markdown output, black-and-white window, EN/RU interface.

## Highlights

- **One file** — `WinHealthAudit.exe` carries the window, the interface and
  the engine; it unpacks into `%LOCALAPPDATA%\WinHealthAudit` on first run.
- **Nine checks** — system, hardware, disks/page file, performance counters,
  WHEA errors, event logs, device manager, processes/services/startup, system
  state — sorted `Info < Warning < Critical`.
- **Window or console** — Edge `--app` window (falls back to your default
  browser) or `WinHealthAudit.Core.exe` with `--days/--json` and exit codes.
- **EN / RU**, guided tour on first run, optional *Start with Windows*.
- **Read-only** — no installer, no service, no driver, no telemetry; the
  server binds `127.0.0.1` only.

## Download

| File | For whom |
| --- | --- |
| `WinHealthAudit.exe` | everyone — the whole app |
| `WinHealthAudit.Core.exe` | automation — CLI engine (`--json`, exit code = critical count) |

**Windows 10/11 only** (stock PowerShell 5.1 + .NET Framework, nothing to install).

> The binaries are unsigned: SmartScreen will say "Windows protected your PC" —
> **More info → Run anyway**.

<summary>Русская версия</summary>

Первый публичный релиз: отчёт о здоровье Windows **в одном исполняемом
файле** — девять проверок, markdown-отчёт, чёрно-белое окно, интерфейс EN/RU.

- **Один файл** — распаковывается в `%LOCALAPPDATA%\WinHealthAudit` при первом запуске
- **Девять проверок** — система, оборудование, диски/файл подкачки, счётчики,
  WHEA, журналы событий, диспетчер устройств, процессы/службы, состояние системы
- **Окно или консоль** — `WinHealthAudit.Core.exe` с `--days/--json`
- **Только чтение** — без установки, служб, драйверов и телеметрии

Скачайте `WinHealthAudit.exe` и запустите двойным щелчком. Если Windows
покажет «Защитила ваш ПК» — **«Подробнее → Всё равно запустить»**.
Необходимы только штатные Windows 10/11.
