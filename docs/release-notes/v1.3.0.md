The audit now remembers: a History tab with a health sparkline, read-only
replays of old runs, a diff inside the report, a tray balloon — and a way to
silence a whole family of findings at once.

## Highlights

- **History tab** — every finished audit is recorded (50 summaries, the
  last 10 keep their full result): a health sparkline over time, average /
  best / worst scores, and a table with the run window, per-severity counts,
  findings and a `Δ` health column. Click a row to reopen that exact run —
  the findings, checks and counts you see belong to the past, a banner says
  so, and *Back to current* (or `Esc`) returns to the live state.
- **The report diffs too** — markdown reports gained a *Since the previous
  run* section: how many findings are new, which ones arrived and which
  resolved (the same normalized comparison the window uses).
- **Hide all of this kind** — the expanded finding now has two buttons:
  *hide this finding* and *hide all of this kind*. The second stores a
  `rule:<id>` entry and clears every finding produced by that rule (both
  low-space volumes, for example). Entries live in `settings.json`; the
  *hidden* chip brings them back.
- **Tray balloon when a run finishes** — health score and counts, in your
  interface language. New setting: *Notify when a run finishes* (on by
  default).
- **Hotkeys** grew a fourth page: `1` `2` `3` `4` = Findings / Checks /
  History / Log. (`R` re-run, `/` filter, `Esc` — out of history, clear
  filter, fold rows.)

**Version 1.3.0** — same one executable, same read-only behaviour.

<summary>Русская версия</summary>

Аудит теперь помнит: вкладка «История» со спарклайном здоровья, просмотр
старых запусков, диф в отчёте, пузырь в трее и кнопка заткнуть целое
семейство находок разом.

- **Вкладка «История»** — каждый завершённый аудит записывается (50 сводок,
  последние 10 хранят полный результат): спарклайн здоровья, средняя /
  лучшая / худшая оценка и таблица с окном, счётчиками по серьёзности,
  числом находок и колонкой `Δ`. Клик по строке открывает этот запуск
  заново — находки, проверки и счётчики из прошлого, баннер это
  показывает; *К текущему* (или `Esc`) возвращает в реальность.
- **Диф появился и в отчёте** — markdown получил секцию *Since the previous
  run*: сколько находок новых, какие пришли и какие ушли (те же
  нормализованные ключи, что и в окне).
- **Скрыть все такие** — в раскрытой находке теперь две кнопки: *скрыть эту
  находку* и *скрыть все такие*. Вторая пишет `rule:<id>` и убирает все
  находки этого правила (например, оба тома с мало места). Список живёт в
  `settings.json`, возвращает его фильтр *скрытые*.
- **Пузырь в трее по завершении** — оценка и счётчики на языке интерфейса.
  Новая настройка *Уведомлять о завершении проверки* (по умолчанию включена).
- **Горячие клавиши** получили четвёртую страницу: `1` `2` `3` `4` =
  Находки / Проверки / История / Журнал. (`R` — повтор, `/` — фильтр,
  `Esc` — выход из истории, сброс фильтра, свернуть строки.)

Версия 1.3.0 — тот же один исполняемый файл и только чтение.
