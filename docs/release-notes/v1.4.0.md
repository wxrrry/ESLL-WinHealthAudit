Two new checks, trends in the history, an auto-repeat timer — eleven
audits' worth of eyes on the machine, and the numbers that drift now
have their own sparklines.

## Highlights

- **Gaming profile check** — display refresh rate (is it actually running
  at its rated Hz?), Game Mode state including the policy override,
  capture / GameDVR / background recording switches, hardware-accelerated
  GPU scheduling, and a power plan that throttles the machine. Wired for
  the EN/RU interface like every other check.
- **Boot performance check** — how many boots happened in the window and
  how long they took. Run elevated and it reads Diagnostics-Performance
  for degraded boots (>60 s) and the Fast Startup state; without
  administrator rights it reports what it can and says so instead of
  guessing.
- **Signals** — the engine now emits machine-readable numbers per run
  (`wheaPerMin`, `cFree`, `bootSec` …) into the JSON output, and the
  history keeps them.
- **Trends** — the History tab grew a trends block above the table: tiny
  sparklines for WHEA errors per minute, free space on `C:` and boot time,
  each with the current value and a delta. Two samples are enough to start
  a line.
- **Auto-repeat** — a new Settings segment (off / 1 h / 4 h / 12 h) re-runs
  the audit while the window is open, so trends and history fill
  themselves in.
- **Smarter balloon** — when health drops between runs, the finishing
  balloon turns into a warning naming the change instead of the usual
  "all done".
- **Hidden findings manager** — Settings now lists everything you hid
  (single findings and whole rules) with a one-click *restore* and a
  *clear all* button; the JSON endpoint behind it grew `?all=1`.

**Version 1.4.0** — same one executable, same read-only behaviour.

<summary>Русская версия</summary>

Две новые проверки, тренды в истории и таймер автоповтора — одиннадцать
пар глаз за машиной, а дрейфующие числа получили собственные
спарклайны.

- **Игровой профиль** — частота обновления дисплея (идёт ли он на
  паспортной?), состояние Игрового режима с учётом политики, переключатели
  захвата / GameDVR / фоновой записи, аппаратное ускорение GPU и схема
  питания, которая тормозит систему.
- **Скорость загрузки** — сколько загрузок было за окно и сколько они
  длились. С правами администратора читает Diagnostics-Performance:
  деградировавшие загрузки (>60 с) и состояние Fast Startup; без прав
  сообщает то, что может, и честно об этом говорит.
- **Сигналы** — движок отдаёт в JSON машиночитаемые числа за прогон
  (`wheaPerMin`, `cFree`, `bootSec` …), и история их запоминает.
- **Тренды** — над таблицей истории блок трендов: мини-спарклайны ошибок
  WHEA в минуту, свободного места на `C:` и времени загрузки с текущим
  значением и дельтой. Двух замеров уже хватит, чтобы начать линию.
- **Автоповтор** — новый сегмент в настройках (выкл / 1 ч / 4 ч / 12 ч)
  перезапускает аудит, пока окно открыто, — история и тренды
  наполняются сами.
- **Умный пузырь** — если здоровье упало, пузырь по завершении превращается
  в предупреждение с указанием изменения, а не в обычное «готово».
- **Менеджер скрытого** — настройки теперь показывают всё, что вы скрыли
  (отдельные находки и целые правила), с восстановлением в один клик и
  кнопкой «очистить»; за этим стоит новый параметр `?all=1`.

Версия 1.4.0 — тот же один исполняемый файл и только чтение.
