Findings now explain themselves: expandable rows, a text filter, advice in
your language — and the app finally owns the tray and the taskbar icon.

## Highlights

- **Click a finding** — the row opens with three lines: *what was checked*
  (which WMI class, log or counter), *where the finding came from* (event id,
  provider, disk name) and *what to do* about it. Every engine finding now
  carries a stable rule id, its source detail and a recommendation; the RU
  interface translates the advice.
- **Filter box** above the findings list narrows the rows as you type
  (message, source, evidence and advice are searched); `Esc` clears it.
  Rows toggle with `Enter` / `Space` and announce their state to screen
  readers.
- **Tray icon** with the project logo: open the window, run an audit, quit —
  and the same logo now sits on the taskbar / window instead of the default
  Edge mark.
- **Richer reports** — the markdown report gained "What was checked" under
  every check and "Checked / Do" lines under every finding; the JSON output
  gained `rule`, `detail` and `advice` on findings and `detail` on checks.
- **Event-log rules grew advice** — the known-issue table (NTFS hangs, disk
  resets, bugchecks, service failures, WHEA dominance and more) now tells you
  what to do in one sentence, in English and Russian.

**Version 1.1.0** — same one executable, same read-only behaviour.
